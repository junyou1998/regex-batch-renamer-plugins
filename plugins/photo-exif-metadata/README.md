# 📷 相片 EXIF 與規格標註外掛 (Photo EXIF & Metadata)

本外掛為原生檔案感知型外掛，直接讀取本機圖片與相片檔頭 EXIF 元數據，極速解析拍攝時間、相機型號、攝影曝光參數與圖像解析規格，並依自訂樣板自動批次重命名。

---

## 🌟 核心特性

- **完整 EXIF 支援**：支援讀取相機品牌、型號、鏡頭、光圈、快門速度、感光度 (ISO) 與實體焦距。
- **拍攝日期與時間戳**：精準提取拍攝當下的原始時間（`DateTimeOriginal`），若無 EXIF 則智慧回退至檔案建立/修改時間。
- **圖像尺寸與規格解析**：支援 **JPEG, PNG, WebP, GIF, BMP**，自動計算寬高、長寬比（16:9, 4:3, 1:1, 9:16 等）與 4K/2K/1080p 規格標籤。
- **相機方向自動校正**：自動根據 EXIF Orientation (1~8) 旋轉方向調整寬高尺寸。
- **自訂樣板彈性混搭**：在輸入框自由搭配任意變數，自動清除未命中變數產生之連續贅餘底線。

## ⚙️ 設定選項

- **常用命名樣板**：提供多種開箱即用的預設樣板（如 `拍攝日期_原檔名`、`拍攝時間_相機_原檔名`、`原檔名_寬x高` 等）。
- **自訂樣板**：支援完全自訂樣板字串，填寫後將優先採用。
- **自動簡化解析度**：預設開啟，將寬高自動簡化為 `4K`、`2K`、`1080p`、`720p`。
- **自動將相機型號空格轉換為底線**：預設開啟，將 `Pixel 8 Pro` 自動轉換為 `Pixel_8_Pro`，避免檔名中出現空格。

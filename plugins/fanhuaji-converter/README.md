# 繁簡互轉 (繁化姬) 插件

透過 [繁化姬 API (zhconvert.org)](https://zhconvert.org) 進行高品質繁簡互轉與專業用語在地化轉換。

---

## ✨ 核心特性

- **高品質用語在地化**：支援台灣正體、香港繁體、簡體中文與中國大陸用語轉換。
- **智慧詞彙對應**：自動處理特定語境詞彙（如 `钢铁侠` $\rightarrow$ `鋼鐵人`、`软件` $\rightarrow$ `軟體`、`网络` $\rightarrow$ `網路`）。
- **極致流量優化**：
  - 內建 5 分鐘記憶體快取，相同文字 0 毫秒直接命中。
  - 全量批次合併請求，100 個檔案僅需 1 次網路連線。
- **副檔名安全防護**：自動略過副檔名字尾（如 `.mp4`, `.jpg`），確保副檔名結構完好。

---

## ⚙️ 可設定選項

| 選項名稱 | 類型 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| **轉換模式** (`converter`) | 選單 | `Taiwan` | 支援 `Taiwan`（台灣正體）、`HongKong`（香港繁體）、`Simplified`（簡體中文）、`China`（大陸用語） |
| **保留副檔名** (`ignoreExtension`) | 開關 | `true` | 自動保護副檔名不被轉換 |
